结构光3D重建系统

从零搭一套结构光 3D 重建系统，这一页记下学到的知识点和搭的过程。

知识点

极线约束 N 步相移

极线约束

左图中一点 P1 在右图里的对应点 P2，一定落在右极线上。 所以匹配时不用搜整张图，只搜一条线。

基本概念

名称定义常用记号
光心 C1、C2两个相机的中心O1、O2
基线两个光心的连线 C1C2—
极平面空间点 P 和 C1、C2 三点构成的平面—
极点基线与成像平面的交点e1、e2
极线极平面与成像平面的交线l1、l2

注意：课件用 e 表示极线、f 表示极点，和主流教材（SLAM 十四讲、OpenCV）是反的。

推理过程

  1. 单目看不出深度

    已知 P1，只能确定 P 在射线 C1→P1 上。

  2. 射线投到右相机是一条直线

    射线和基线在同一个极平面里，极平面与右成像面相交得到的就是右极线 l2。

  3. 所以 P2 在 l2 上

几个性质

  • 每条极线都经过极点
  • 同一幅图里的所有极线交于同一个极点（极平面绕着基线转）
  • 左右极线成对出现，都来自同一个极平面

作用

  • 降维：匹配搜索从二维平面降到一维直线，计算量大幅减少
  • 减少误匹配：不在极线上的候选点直接排除
  • 立体校正：把极线变成水平且左右行对齐，匹配只需在同一行里找，由此得到视差

N 步相移：从亮度求相位

让条纹按已知幅度移动，记录同一个像素的亮度变化，再由这些亮度反推出该像素的相位。

1. 相位表示一个点处在条纹周期的什么位置

正弦条纹的亮度会按“亮 → 暗 → 亮”周期性变化。用角度描述这个过程：

一个条纹周期中的相位与亮度
相位亮度状态
0°最亮
90°中间亮度，正在变暗
180°最暗
270°中间亮度，正在变亮
360°再次最亮，进入下一周期

一张图里，中间亮度可能对应 90°，也可能对应 270°。再加上不同位置本身的亮度和条纹对比度可能不同，只看一张图，通常无法唯一确定相位。相移法通过多张图消除这些歧义。

2. N 步，就是给条纹施加 N 个已知的相位偏移

例如四步相移，依次加入 0°、90°、180°、270° 的偏移。物体、相机保持不动，改变的是条纹的相位。对某个固定像素，亮度模型为：

Ik = A + B cos(φ + δk)
亮度模型中的未知量
符号含义
A平均亮度，决定整体偏亮还是偏暗
B条纹调制幅度，决定明暗变化有多强，取 B ≥ 0
φ这个像素原本的相位，是我们要解的量

每张图给出一个亮度观测值，多张图共同约束这三个未知量。在这个模型下，至少需要三个合适的相移位置。同一个像素在不同图片里的 A、B、φ 应当保持一致，只有已知的 δk 发生变化。

如果某处 B 接近 0，说明这个像素几乎没有条纹亮度变化，它的相位也就难以可靠求出。

3. 用四步相移，看相位怎样算出来

把四个偏移量代入，并用三角函数关系展开：

I0 = A + B cos φ
I1 = A − B sin φ
I2 = A − B cos φ
I3 = A + B sin φ

两两相减：

I0 − I2 = 2B cos φ
I3 − I1 = 2B sin φ

这一步很关键：相减消除了平均亮度 A，得到了一对分别与余弦、正弦成正比的数。于是：

φ = atan2(I3 − I1, I0 − I2)

atan2(y, x) 可以理解成：已知一个方向的纵向分量和横向分量，求它的角度。两个分量都有相同的系数 2B，所以角度不受这个系数影响。普通的 arctan(y/x) 无法完整区分四个象限，因此这里使用 atan2。

例如 I0 − I2 = 40，I3 − I1 ≈ 69.3，那么 φ = atan2(69.3, 40) ≈ 60°。这就解出了该像素的相位。对整张图的每个像素重复这个计算，就得到一张相位图。

4. 从四步推广到 N 步，原理相同

对于覆盖一个周期、等间隔的 N 步相移，取 N ≥ 3：

δk = 2πk / N，k = 0, …, N − 1

分别把各张图的亮度乘以对应的余弦和正弦，再求和。下面的 Σ 都表示对 k = 0 到 N − 1 求和：

C = Σ Ik cos δk
S = Σ Ik sin δk

由于这些相移位置均匀分布，求和后，平均亮度项以及交叉项会抵消，留下：

C = (NB / 2) cos φ
S = −(NB / 2) sin φ

所以 N 步相移的核心公式是：

φ = atan2(−S, C)

负号来自这里采用的 cos(φ + δk) 模型。如果仿真采用减号，或图像顺序不同，相应公式也要调整；已知但不等间隔的相移，可以通过最小二乘拟合求解，不能直接套用上面的等间隔求和公式。

5. 为什么解出相位后，还需要“解包裹”

正弦函数每隔 2π 就重复一次：

cos φ = cos(φ + 2π) = cos(φ + 4π)

因此，上述计算只能判断一个点在当前周期内的位置，无法直接判断它属于第几个周期。得到的通常是 [−π, π] 范围内的“包裹相位”。

例如真实相位沿一行逐渐增加，从 0、0.5π 一直增加到 2π、2.5π，计算结果却会折回到同一个范围，出现约 2π 的跳变。解包裹就是确定每个位置应补上多少个 2π：

Φ(x, y) = φ(x, y) + 2πm(x, y)

整数 m 表示周期级次。空间连续性、多频条纹、格雷码等，都可以为确定这个整数提供条件。空间展开还依赖采样足够密、噪声较小等条件；仅凭单频 N 张图，一般不能唯一确定绝对级次，不连通区域之间也可能存在独立的周期歧义。

6. 相位图与三维重建是什么关系

处理一组仿真图时，先利用各像素随相移变化的亮度求包裹相位，再根据仿真条件判断怎样展开。相位通常还包含投影条纹本身的变化，不能直接把相位数值当成物体高度。恢复高度或面形，还需要相应的参考关系或标定与几何模型。

求解是否可靠，可以结合条纹调制度、亮度模型的拟合残差，以及与仿真真实相位的误差来检查。
